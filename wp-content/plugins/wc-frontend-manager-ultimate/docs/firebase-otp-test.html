How to use idToken in Postman

Login endpoint

POST https://aaraakart.com/wp-json/aaraakart/v1/auth/login
Content-Type: application/json

{
  "phone": "+919876543210",
  "firebase_id_token": "PASTE_ID_TOKEN_HERE"
}

Register endpoint

POST https://aaraakart.com/wp-json/aaraakart/v1/auth/register
Content-Type: application/json

{
  "phone": "+919876543210",
  "firebase_id_token": "PASTE_ID_TOKEN_HERE",
  "first_name": "Ravi",
  "last_name": "Kumar",
  "email": "ravi@example.com"
}

The response will contain a token (JWT). Use it as:

GET https://aaraakart.com/wp-json/aaraakart/v1/auth/me
Authorization: Bearer JWT_TOKEN_HERE

⚠️ idToken expires in 1 hour. Run this page again to get a fresh one if it expires.
